# Gambaran Utuh HMTE TRE SV UGM dan Website

Dokumen ini merangkum informasi utama yang saat ini tersedia di repo `WEBSITE-HMTE`: konteks organisasi HMTE, sistem warna yang dipakai, dan gambaran website yang sedang dibangun. Informasi dibagi antara data yang sudah bersumber dari publik dan data yang masih perlu dikonfirmasi ke pengurus.

## 1. Informasi Tentang HMTE

### Identitas Organisasi

HMTE TRE SV UGM adalah singkatan dari **Himpunan Mahasiswa Teknik Elektro Teknologi Rekayasa Elektro Sekolah Vokasi Universitas Gadjah Mada**.

Dalam struktur kelembagaan, HMTE berada dalam lingkup:

- Program Studi: **Teknologi Rekayasa Elektro**
- Departemen: **Departemen Teknik Elektro dan Informatika**
- Fakultas/Sekolah: **Sekolah Vokasi**
- Universitas: **Universitas Gadjah Mada**

Nama organisasi yang digunakan dalam website adalah:

> HMTE TRE SV UGM

Nama panjang yang digunakan:

> Himpunan Mahasiswa Teknik Elektro

Slogan/kultur yang digunakan dalam konten website:

> Elektro... Satu!!!

### Posisi dan Peran HMTE

HMTE diposisikan sebagai ruang organisasi mahasiswa Teknik Elektro di Program Studi Teknologi Rekayasa Elektro SV UGM. Website ini memandang HMTE sebagai rumah informasi untuk:

- kegiatan mahasiswa,
- program kerja,
- kepengurusan,
- divisi atau bidang,
- prestasi,
- galeri dokumentasi,
- alumni,
- kontak dan kolaborasi,
- arsip kemahasiswaan.

Dengan kata lain, HMTE tidak hanya ditampilkan sebagai organisasi formal, tetapi sebagai pusat aktivitas mahasiswa elektro yang menghubungkan akademik, kaderisasi, kegiatan, publikasi, prestasi, relasi industri, alumni, dan kolaborasi.

### Informasi yang Sudah Terkonfirmasi dari Sumber Publik

Informasi berikut sudah dianggap sebagai dasar publik awal:

- TRE berada di bawah Departemen Teknik Elektro dan Informatika, Sekolah Vokasi UGM.
- DTEDI menekankan pendidikan vokasi yang menghasilkan lulusan profesional siap pakai.
- Ruang bidang yang berkaitan dengan DTEDI/TRE mencakup elektro arus kuat, elektro arus lemah, instrumentasi, dan teknologi informasi.
- Website TRE aktif memuat berita kegiatan riset, industri, semikonduktor, capstone, kunjungan industri, dan prestasi mahasiswa.
- Halaman HMTE di website TRE menampilkan kanal Instagram publik HMTE Gadjah Mada `@hmteugm`.
- Halaman HMTE TRE memuat bagian kepengurusan tahun 2025 melalui embed Instagram.

### Informasi yang Masih Perlu Dikonfirmasi ke Pengurus

Website ini sengaja tidak mengarang data yang belum valid. Bagian berikut masih perlu dikonfirmasi langsung ke pengurus HMTE:

- logo resmi dalam SVG/PNG resolusi tinggi,
- filosofi logo dan aturan penggunaan logo,
- visi, misi, nilai, tagline, dan narasi resmi HMTE,
- struktur kepengurusan terbaru,
- nama ketua, wakil, sekretaris, bendahara, dan koordinator bidang,
- foto pengurus resmi,
- nama bidang/divisi resmi,
- daftar program kerja terbaru beserta deskripsi,
- dokumentasi kegiatan yang boleh dipublikasikan,
- prestasi mahasiswa dan prestasi atas nama HMTE,
- arsip berita, caption kegiatan, dan press release,
- link sosial media resmi,
- email, nomor kontak, alamat sekretariat, dan kanal kolaborasi,
- data alumni, partner, sponsor, atau mitra industri.

### Model Status Informasi

Repo ini memakai tiga status untuk menjaga informasi tetap jujur:

- **Terkonfirmasi**: data sudah punya sumber publik awal.
- **Indikasi publik**: data terlihat dari media sosial atau embed publik, tetapi detailnya belum disalin sebagai fakta final.
- **Perlu dikonfirmasi ke pengurus**: data belum boleh dianggap resmi.

Pendekatan ini penting karena website organisasi mahasiswa harus terlihat kredibel tanpa membuat klaim palsu.

## 2. Informasi Design Color

Sistem warna saat ini dibuat untuk memberi kesan **teknis, hangat, mahasiswa, vokasi, elektro, dan kredibel**. Warna final masih perlu divalidasi ulang dari arsip poster/logo resmi HMTE, tetapi palette ini sudah dipakai sebagai MVP website.

### Warna Dominan

#### Deep Engineering Ink

- HEX: `#0f2437`
- Peran: warna dominan utama
- Dipakai untuk: identitas teknis, area gelap, footer, teks penting, latar hero/section tertentu
- Kesan: serius, teknik, stabil, kredibel

#### Near Black / Switchboard Black

- HEX: `#071019` atau `#081521`
- Peran: warna dominan untuk homepage creative switchboard
- Dipakai untuk: hero gelap, activity console, source ledger, photo belt
- Kesan: laboratorium elektro, panel kontrol, ruang kerja teknis

#### Warm Paper

- HEX: `#f6f2ea` dan variasi `#f4efe4`
- Peran: warna dominan terang
- Dipakai untuk: background halaman, section terang, area baca
- Kesan: hangat, editorial, tidak terlalu corporate

### Warna Pendukung

- HEX: `#155e75`
- Peran: warna pendukung utama
- Dipakai untuk: aksen elektro, link, ikon, status, detail UI

#### Bright Cyan

- Peran: aksen visual pada homepage switchboard

## 3. Informasi Tentang Website

### Tujuan Website

Website ini dirancang sebagai website resmi/draft resmi HMTE TRE SV UGM yang:

- kredibel,
- hangat,
- responsif,
- mudah diperbarui,
- tidak terasa seperti template generik,
- tidak mengarang fakta,
- bisa menjadi pusat informasi kegiatan dan organisasi.

Website diarahkan untuk memperkenalkan HMTE kepada mahasiswa, calon mahasiswa, dosen, alumni, mitra, sponsor, dan pihak eksternal yang ingin mengenal atau bekerja sama dengan HMTE.

### Stack Teknologi

Website dibangun menggunakan:

- Next.js
- React
- TypeScript
- lucide-react untuk ikon
- Vitest dan Testing Library untuk test
- CSS global custom untuk design system

Struktur konten utama dipusatkan di:

```text
src/data/site-content.ts
```

Tujuannya agar data organisasi, berita, program, divisi, galeri, kontak, dan checklist bisa diganti tanpa harus membongkar komponen halaman satu per satu.

### Struktur Halaman

Website memiliki halaman:

- Beranda
- Tentang
- Kepengurusan
- Divisi
- Program Kerja
- Berita
- Prestasi
- Galeri
- Alumni
- Kontak

### Konsep Homepage

Homepage memakai konsep visual **creative switchboard**. Artinya, HMTE divisualkan seperti panel kerja elektro: ada routing board, activity console, impact wall, division map, photo belt, verification table, dan source ledger.

Bagian homepage:

- Hero identitas HMTE TRE SV UGM
- Quick navigation/frequency deck
- Program kerja sebagai routing board
- Kegiatan terbaru sebagai activity console
- Prestasi sebagai impact wall
- Divisi sebagai division map
- Galeri sebagai photo belt
- Checklist data sebagai verification table
- Catatan riset sebagai source ledger
- CTA kontak/kolaborasi

Pendekatan ini membuat website terasa lebih khas elektro dan tidak sekadar halaman organisasi standar.

### Karakter Visual Website

Karakter desain website:

- teknis, tetapi tetap hangat,
- resmi, tetapi tidak terlalu corporate,
- aktif seperti organisasi mahasiswa,
- punya nuansa elektro/laboratorium/panel kontrol,
- rapi untuk dibaca,
- visualnya lebih berani di homepage,
- halaman turunan dibuat lebih sederhana agar informasi mudah dipindai.

### Typography

Typography yang dipakai:

- Heading/display: `Source Serif 4`, fallback `Newsreader`, `Georgia`, serif
- Body/UI: `Plus Jakarta Sans`, fallback `Geist`, `IBM Plex Sans`, system sans

Heading serif memberi rasa editorial dan hangat, sementara body sans-serif menjaga website tetap bersih dan modern.

### Komponen Utama

Komponen utama website:

- Header dengan brand mark HMTE dan navigasi
- Footer dengan navigasi, kontak, dan sumber awal
- Status tag untuk membedakan data valid dan data yang perlu konfirmasi
- Page intro untuk halaman turunan
- Section shell untuk pola section reusable

### Konten yang Sudah Ada

Konten awal yang sudah dimasukkan:

- identitas organisasi HMTE TRE SV UGM,
- relasi kelembagaan dengan TRE, DTEDI, SV UGM,
- sumber publik awal,
- program kerja model awal,
- berita publik dari website TRE,
- prestasi publik dari konteks TRE,
- divisi placeholder,
- galeri placeholder dari dokumentasi TRE,
- kontak Instagram,
- checklist data yang perlu diminta ke pengurus.

### Konten yang Belum Final

Konten yang masih harus diganti dengan data resmi:

- logo HMTE,
- struktur kepengurusan,
- nama dan foto pengurus,
- divisi resmi,
- program kerja resmi,
- arsip kegiatan HMTE,
- prestasi khusus HMTE,
- galeri resmi HMTE,
- email dan kontak resmi,
- alumni dan partner.

### Prinsip Penting Website

Website ini mengikuti satu prinsip penting:

> Kalau data belum jelas, tampilkan sebagai belum jelas.

Itu sebabnya banyak bagian memakai label `Perlu dikonfirmasi ke pengurus`. Label ini bukan kelemahan website, tetapi mekanisme agar website tidak menyebarkan informasi yang belum resmi.

### Cara Menjalankan

Install dependency:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Build production:

```bash
npm run build
```

Jalankan test:

```bash
npm test
```

## 4. Ringkasan Paling Pendek

HMTE TRE SV UGM adalah Himpunan Mahasiswa Teknik Elektro pada Program Studi Teknologi Rekayasa Elektro, Departemen Teknik Elektro dan Informatika, Sekolah Vokasi UGM. Website ini dibuat sebagai rumah informasi resmi/draft resmi untuk organisasi, program kerja, kegiatan, prestasi, galeri, alumni, dan kolaborasi.

Warna dominan website adalah gelap teknis (`#0f2437`, `#071019`, `#081521`) dan terang hangat (`#f6f2ea`, `#f4efe4`, `#fffdf5`). Warna pendukungnya adalah teal/cyan elektro (`#155e75`, `#22c7d7`), gold UGM/energi mahasiswa (`#f5b82e`, `#f7bd2e`), serta orange aksen (`#ef6f2e`).

Website memakai Next.js, React, TypeScript, CSS custom, dan data terpusat di `src/data/site-content.ts`. Konsep visual homepage adalah creative switchboard: website terasa seperti panel kerja elektro yang rapi, aktif, teknis, dan tetap hangat untuk organisasi mahasiswa.
