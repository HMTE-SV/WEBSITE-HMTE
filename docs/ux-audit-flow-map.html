Temuan awal dari pemetaan (titik mulai audit)

  • /agenda dan /pengumuman jalan buntu — tidak ada tautan lanjutan setelah user membaca, dan keduanya rawan tampil kosong (EmptyState) bila data belum diisi.
  • Kartu /galeri menaut ke artikel berita — tidak ada lightbox atau halaman detail galeri; ekspektasi user melihat foto besar tidak terpenuhi.
  • /aspirasi berhenti setelah submit — tidak ada arahan lanjut (kembali ke beranda, lihat aspirasi lain, dsb.) setelah pesan sukses.
  • /berita/[slug] tanpa artikel terkait — pembaca selesai membaca lalu tidak ditawari konten lain; satu-satunya jalan adalah tombol kembali.
  • /kontak paling sederhana padahal target CTA utama — tombol "Hubungi" di Header selalu terlihat, tapi mendarat di halaman berisi 3 kartu statis.
