# TRE Landing — UI Kit

A hi-fi recreation of the proposed TRE marketing landing page, built against the design system tokens in `../../colors_and_type.css`.

## Files

- `index.html` — full assembled landing page
- `Header.jsx` — fixed top nav with backdrop blur + red active underline
- `Hero.jsx` — near-black full-bleed hero with display headline + accreditation badge
- `StatStrip.jsx` — three-up mono numerals on dark
- `Pillars.jsx` — three pillars of the program (pembangkitan / transmisi / instalasi)
- `Curriculum.jsx` — semester-grouped course list
- `Partners.jsx` — industry partner wordmark wall
- `CTA.jsx` — admissions call-to-action band
- `Footer.jsx` — institutional address block

## Notes

This is a **proposed** landing page — not a recreation. No existing TRE codebase or Figma was provided. Components are intentionally simple/cosmetic (no real form handling, no router) and meant to be lifted into real designs.

The visual vocabulary follows the brief strictly: alternating dark/light section rhythm, generous (120–160px) vertical padding, Syne for display, Inter for body, JetBrains Mono for stats. Red accent appears 4 times across the page — never decoratively.
